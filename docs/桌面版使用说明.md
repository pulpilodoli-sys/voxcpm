# 叙幕桌面版

启动程序后再填写密钥即可，不需要修改代码或创建密钥文件。密钥只留在本次运行内存中，退出后需要重新填写。不要把密钥发给开发者。

## 使用

1. Windows：解压完整 ZIP，双击 DramaScript.exe，保留旁边的 _internal 文件夹。macOS：打开 DMG，将 DramaScript.app 拖入“应用程序”，再启动。
2. 选择视频及新的空项目文件夹。
3. 云端模式：填写服务商兼容 OpenAI 的地址、视觉模型、转写模型和 API 密钥。使用前在服务商处开通对应模型。点击开始才上传音画。
4. 本地模式：先启动本机兼容 OpenAI 的视觉服务，例如 Ollama，下载支持图像的模型，再在软件填写本机接口与模型名。首次本地语音识别还需要下载 Whisper 模型。软件包不包含大型 AI 模型。
5. 分析后核对原片及证据，修改中文剧本，保存修订并导出 DOCX / PDF。

无对白画面会生成文字描述；对白归属不明时保留待核实。当前版本尚未通过真实长片、多人物身份与完整剧情连贯性验收，请核对生成稿。

## 构建与交付状态

Windows x64 已在 GitHub Windows runner 构建并通过 38 项测试、冻结程序启动及内置视频组件检查。[下载 Windows 包](https://github.com/pulpilodoli-sys/voxcpm/actions/runs/39963300752/artifacts/12506365570)（需要登录有仓库访问权限的 GitHub 账号）。GitHub 下载包内有 DramaScript-win32.zip，请再次解压后运行 DramaScript.exe。macOS 尚未构建。

源码包中 scripts/构建Windows.cmd 和 scripts/构建macOS.command 提供双击构建入口。**仅构建电脑**需先安装 Python 3.12 和 FFmpeg，并联网安装依赖；生成的桌面软件自带 Python 与视频组件。构建无需 API 密钥。输出位于 dist。

macOS 构建依照构建机架构；Apple Silicon 包不能视为 Intel Mac 已通过验证。包目前未签名、公证，也没有自动更新功能。

用户已授权将代码推送到 windows-desktop-build 专用分支，Windows 构建结果以该分支 build-results/windows.json 为准；main 不修改。
